# Screenshots

Drop your product screenshots in this folder using the exact filenames below.
The root [`README.md`](../../README.md) references them, so they'll render as soon
as the files exist. PNG at ~1600px wide (retina) looks best on GitHub.

| Filename | What to capture |
|----------|-----------------|
| `hero.png` | The public home page (`/`) — the "Write. Publish. Grow." hero and featured posts. |
| `editor.png` | The post editor (`/blogs/new`) showing the Markdown editor and live SEO score. |
| `dashboard.png` | The authenticated dashboard (`/dashboard`) with the Chartkick analytics charts. |
| `analytics.png` | A single post's analytics view (views over time). |
| `demo.gif` | *(optional)* A short screen recording of the publishing flow. |

## Tips

- Use light **or** dark theme consistently across shots (the app supports both).
- Crop out browser chrome, or use a clean frame, for a polished look.
- Keep each image under ~1 MB so the README stays fast to load.
